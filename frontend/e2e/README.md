# E2E Tests

End-to-end tests for OpenClaw Machines, running against the production site.

## Two Test Runners

### 1. Puppeteer (Chrome automation) — `chrome-e2e.mjs`

Uses `puppeteer-core` to drive a real Chrome browser window. The browser is visible (not headless) so you can watch the test run in real time.

#### Prerequisites

- **Node.js 20+** and `npm install` in `frontend/`
- **Google Chrome** installed:
  - macOS: `/Applications/Google Chrome.app` (default)
  - Linux: set `CHROME_PATH` in the script to your Chrome/Chromium path
  - Windows: set `CHROME_PATH` to `C:\Program Files\Google\Chrome\Application\chrome.exe`

#### Running

```bash
cd frontend

# API key already saved in account — skip key setup
node e2e/chrome-e2e.mjs

# First run / set API key via the Settings UI
ANTHROPIC_KEY="sk-ant-..." node e2e/chrome-e2e.mjs

# Custom login credentials
TEST_EMAIL="you@example.com" TEST_PASSWORD="pass" node e2e/chrome-e2e.mjs
```

#### Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `ANTHROPIC_KEY` | *(none)* | Anthropic API key to save via Settings UI. Omit to skip key setup. |
| `TEST_EMAIL` | `integtest@openclawmachines.com` | Login email |
| `TEST_PASSWORD` | `TestPass123!` | Login password |

#### What It Tests (Full Pipeline)

1. Login to the dashboard
2. *(Optional)* Add Anthropic API key via Settings > API Keys
3. Create a new machine
4. Start the machine, wait for provisioning (~1-3 min)
5. Open workspace, verify shell prompt appears
6. `curl` the LLM apiproxy (`http://192.168.100.1:4000/anthropic/v1/messages`) from inside the VM
7. Verify the LLM response contains `content` and `stop_reason`
8. Stop and delete the machine

Total runtime: ~50-60 seconds (plus VM provisioning time).

#### Screen Recording

Since the test runs in a visible Chrome window, you can record it:

**macOS built-in (easiest):**
1. Press `Cmd + Shift + 5` to open the recording toolbar
2. Select "Record Entire Screen" or "Record Selected Portion"
3. Click Record, then run the test in another terminal
4. Click the stop button in the menu bar when done — saves `.mov` to Desktop

**QuickTime Player:**
- File > New Screen Recording

**ffmpeg (CLI, scriptable):**
```bash
brew install ffmpeg
# Start recording (press q to stop)
ffmpeg -f avfoundation -i "1:none" -r 30 e2e-recording.mp4
```

#### Troubleshooting

| Issue | Fix |
|-------|-----|
| Chrome not found | Set `CHROME_PATH` in `chrome-e2e.mjs` to your Chrome binary path |
| Login fails | Verify credentials — try logging in manually at the same URL |
| Machine stuck provisioning | May be a capacity issue — check GCP Console for VM status |
| LLM curl times out | Verify `ANTHROPIC_API_KEY` is set in the account (check Settings > API Keys) |
| `__LLM_OK__` not received | The curl command may have failed — check terminal output in the browser |
| `puppeteer-core` not found | Run `npm install` in `frontend/` |

### 2. Playwright — `*.spec.ts` files

Uses Playwright's test framework with Chromium. Better for CI and parallel execution.

#### Setup

```bash
cd frontend
npm install
npx playwright install chromium
```

#### Run against production

```bash
cd frontend
PLAYWRIGHT_BASE_URL=https://www.openclawmachines.com npx playwright test
```

#### Run against local dev

```bash
cd frontend
npx playwright test   # auto-starts dev server on localhost:5173
```

#### Test Files

| File | Description |
|------|-------------|
| `auth.setup.ts` | Login setup (saves auth state for other tests) |
| `login.spec.ts` | Login/register page tests |
| `dashboard.spec.ts` | Dashboard navigation tests |
| `settings.spec.ts` | Settings page tab tests |
| `machine-lifecycle.spec.ts` | Full machine lifecycle: create, start, workspace, stop, delete |
| `llm-roundtrip.spec.ts` | LLM request through apiproxy from inside a running VM |

## Auth State

The `e2e/.auth/state.json` file stores the login cookie for authenticated tests. It is regenerated by `auth.setup.ts` on each run.

This file is in `.gitignore` and should not be committed.
