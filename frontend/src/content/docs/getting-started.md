# Getting Started

OpenClaw Machines gives you a full computer — browser, terminal, filesystem — controlled by an AI agent. Each machine is an isolated environment where your agent can browse the web, run code, manage files, and complete tasks autonomously.

## What You Get

Each OpenClaw Machine includes:

- **A full Linux desktop** with a browser, terminal, and file manager
- **An AI agent** (powered by Claude, GPT-4, or other models) that controls the computer
- **Browser automation** via CDP/Playwright for web tasks
- **A gateway** that connects your agent to tools, APIs, and the outside world
- **Persistent storage** so your agent can pick up where it left off

## How It Works

1. **You create a machine** — choose a size, name it, and configure the agent
2. **You add credentials** — API keys for the AI model, plus any services your agent needs
3. **You launch it** — the machine boots in seconds and your agent starts working
4. **You watch or interact** — open the workspace to see the terminal, browser, and agent activity in real time

## What You'll Need

- An OpenClaw Machines account (sign up at [openclawmachines.com](https://openclawmachines.com))
- An API key for at least one AI model provider (Anthropic, OpenAI, Google, etc.)
- A task for your agent — anything from web research to code generation to data processing
